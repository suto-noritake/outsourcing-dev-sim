# acceptance_criteria

## 判定ルール
- 各項目はYes/Noで判定する。すべてYesで検収合格。

## Criteria
- [ ] AC1: コマンドライン引数で渡した式を評価し、標準出力に正しい結果を出す（例: "calc "2+3*4"" -> 14）
- [ ] AC2: 対話モード（REPL）で複数式を順に評価できる（入力ごとに結果を出力し、終了コマンドで退出）
- [ ] AC3: 括弧を含む式を正しく評価する（例: "(2+3)*4" -> 20）
- [ ] AC4: べき乗演算（^）をサポートする（例: "2^3" -> 8）
- [ ] AC5: 小数点を含む計算で合理的な精度を保つ（浮動小数点で計算、極端な精度は除外）
- [ ] AC6: ゼロ除算や構文エラー時に標準エラーへ意味あるメッセージを出力し、非ゼロ終了コードを返す
- [ ] AC7: READMEに実行方法と主要な使用例、エラーコード一覧が記載されている
- [ ] AC8: 主要ケースを網羅する単体テストが含まれており、テストを実行して全パスする

## 備考
- 実装言語は任意だが、依存は最小限に留めること。外部依存がある場合はインストール手順をREADMEに明記する。
