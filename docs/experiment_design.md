# Phase 3: 実験設計マトリクス

## 仮説（検証対象）

- **H1**: 技術力が難易度を上回っている限り、失敗要因としては「実装失敗」より
  「資金枯渇（倒産）」の方が支配的になる
- **H2**: モデルティアを上げるほど成功率は上がるが、コストの非線形増加により
  ある閾値を超えると純利益は低下する（フロンティアモデル濫用は非効率になる）
- **H3**: エージェント数を増やす戦略は、`α`（収穫逓減）が小さいほど有効性が下がる
- **H4**: 「適応戦略」は「保守的戦略」「コスト最適戦略」より長期生存率・利益率で優位

## 実験ステージ

### Stage 0: パイロット試行

Baseline設定で n=100〜300 回試行し、主要指標（成功率、生存ラウンド数、最終資金）の
分散を推定 → 目標CI幅（例: 成功率±2pt, 95%CI）から必要反復数を算出
（正規近似 `n ≈ (z/E)^2 * p(1-p)`、生存ラウンド数は経験分散から算出）

### Stage 1: スクリーニング設計（要因数が多いため全数総当りは行わない）

12個の構造/環境/方策パラメータに対し **Morris法（Elementary Effects）** または
**2水準分解能IV型部分実施要因計画（fractional factorial）** を適用し、
少ない試行数（各設計点 50〜100反復）で「効くパラメータ」を絞り込む。

出力: 各パラメータの標準化効果量ランキング → 上位4〜5個を「集中実験」対象に選定。

### Stage 2: 集中実験（Focused Factorial）

Stage1で選ばれた上位パラメータ × B戦略（3水準）の**完全要因計画**を、
Stage0で決めた反復数（統計的検定力を満たす回数）で実行。

比較の分散低減のため **共通乱数（Common Random Numbers）** を用いる：
同じ乱数シード列を戦略間で共有し、ペア比較の分散を下げる。

### Stage 3: 統計解析

- 二値アウトカム（成功/生存）: ロジスティック回帰、要因のオッズ比を報告
- 生存ラウンド数（打ち切りデータあり）: Kaplan-Meier生存曲線 + Cox比例ハザードモデル
- 連続アウトカム（最終利益等）: ANOVA / 線形回帰、交互作用項（特にstrategy×他要因）に注目
- 多重比較・信頼区間・効果量（Cohen's d等）を明記し、有意水準は事前に設定（例: α=0.05、
  多重検定時はBonferroni/BH補正）

### Stage 4: 再現性の担保

すべての設計点・乱数シード・パラメータ値をrun manifest（JSON/CSV）として記録。
実験条件・結果・解釈をリポジトリ内 `docs/experiments/` に記録し、後から再実行可能にする。
